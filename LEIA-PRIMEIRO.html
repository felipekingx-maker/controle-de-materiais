Controle de Materiais

A URL e a chave pública do seu Supabase já estão configuradas. O próximo passo é abrir o projeto e testar o acesso.

Comece por aqui

  1. Extraia o arquivo ZIP inteiro para uma pasta no computador.
  2. A configuração de conexão em js/config.js já está preenchida; não precisa editar esse arquivo.
  3. Confira se o banco possui o esquema revisado. As instruções estão em README.md. Não execute o SQL de criação de novo sobre um banco já preenchido.
  4. Com Python 3 instalado, abra INICIAR-WINDOWS.bat. A janela deve continuar aberta enquanto você usa o sistema.

Você também pode usar o VS Code com Live Server para abrir o sistema por HTTP.

Use somente a chave publicável/anon. Senha do banco e chave service_role não devem entrar no código.
